# TurboJev — Python

Uses **turbojev 0.30.1 from PyPI**, not local SDK source. Install with the same Python interpreter you use to run the demo.

```powershell
python -m pip install -r requirements.txt
python main.py ticket
python main.py fields
python main.py fair-die --device gpu
python main.py receipt --device gpu --fields first_item,total
python main.py receipt-us --image C:/photos/receipt.jpg --device gpu
```

`ticket` calls `evaluate`; `fields` calls `generate` and demonstrates integers, decimal numbers, boolean probabilities, actual null, dependencies and conditional omission. Other modes dispatch to the existing dedicated Python examples, preserving their full schemas, downloads, model selection and reports. Keep the repository layout.

CPU is the default. GPU is explicit and does not fall back. Text uses Qwen3 0.6B GGUF; image extraction uses Qwen3.5 2B plus a matching projector. Download progress, transfer speed and ETA appear on first use; all languages reuse `~/.cache/turbojev` where compatible. `--model PATH` selects a local GGUF; receipts also accept `--mmproj PATH`. `--fields` selects a recorded subset including dependencies. See `python main.py <example> --help` for each mode's options.

Receipt answers and dependent arithmetic are generated by the model, with expected labels checked only afterward. Full image runs can take minutes and small models can make mistakes. The CORD photo is bundled with attribution; the US photo is not redistributed. See [fair die](../fair-die-python/README.md), [CORD receipt](../receipt-python/README.md) and [US receipt](../receipt-us-python/README.md) for defaults, licenses and full measured results. Reports for ticket/fields default to `result-<example>.json`; other modes retain their dedicated example's output path.

Current PyPI wheels cover Windows x86/x64/ARM64 according to the Python process architecture. Other systems need matching published wheels. A 32-bit process may not fit the default vision model/projector. An older installed TurboJev can reject new options; install the requirements first and verify with `python -m pip show turbojev`.
